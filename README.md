# CodeAlpha Flashcard Quiz App

A responsive smart flashcard app built with HTML, CSS, and vanilla JavaScript.

## Features

- Create, edit, delete, search, and filter flashcards by topic.
- Study cards with reveal, previous/next, shuffle, random practice, and difficulty ratings.
- Take multiple-choice quizzes and track scores and averages.
- View learning statistics, daily goals, and study streaks.
- Save cards and progress in browser LocalStorage.
- Switch between light and dark themes.

## Run locally

Open `index.html` in a modern web browser. No build tools or dependencies are required.
